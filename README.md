# 3D 贪吃蛇（雏形）

45° 俯视视角的立体贪吃蛇。棋盘、蛇身、果实全部是真的 3D 几何体，
不是 2D 贴图伪装的立体感。

## 怎么跑

不需要装任何东西，也不联网：

```
直接双击 index.html
```

或者起个本地服务（想用 localStorage 存最高分的话推荐这种）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/
```

## 操作

| 键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 转向（按的是**屏幕方向**，转过视角也不会按反） |
| `Enter` | 在名字输入框里按，直接开局 |
| `Space` | 暂停 / 继续；死了之后是重开 |
| `R` | 重开 |
| `Q` `E` 或鼠标拖拽 | 左右转视角 |
| `M` 或左下角按钮 | 音效开关 |

### 手机 / 平板

**直接在屏幕上滑动就能转向**，滑的是屏幕方向，跟视角转到哪无关。
一笔画折线可以连着拐两次（滑出去 26px 就算一次，起点会重置）。
右下角也有方向键，习惯按钮的可以用。

**转视角改成双指横拖** —— 单指留给转向了，不然一滑就变成转镜头，
手机上没人找得到怎么控制蛇。

## 测试

打开 **[test.html](https://alexsheng26.github.io/3D-snake/test.html)** 就跑，70 条断言，
浏览器里几百毫秒出结果，绿色全过、红色是哪条挂了。

它不是另抄一份逻辑来测 —— 而是**用 iframe 加载真实的 `index.html`**，
直接操作游戏内部状态。所以测的就是发布出去的那个文件本身，不存在
「测试通过但线上是另一份代码」。

覆盖：走位与碰撞（撞墙 / 撞自己 / 追尾巴尖不算撞 / 不能掉头）、
接头的间距不变量、两种果实的计分与出现规则、计分榜的排序名次存读
和脏数据容错、名字兜底截断与输入框抢键盘、音效的节点数与静音、
手势的四个方向阈值连拐和双指、以及分享用的 meta 标签。

**本地跑**（`file://` 下 iframe 会被跨源拦住，必须起服务）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/test.html
```

改完任何东西，刷新一下这个页面就知道有没有碰坏别的地方。

> 测试会临时写 localStorage，跑完自动还原，不会冲掉你的计分榜。

## 图标和分享卡片

`index.html` 的 `<head>` 里带了 favicon 和分享用的 og 标签，发链接到微信 /
Twitter 会显示一张真实游戏截图的卡片，而不是白板。

- **favicon 是内嵌的 SVG data URI**，没有额外文件，单文件离线打开照样有图标
- `preview.png`（1200×630）是分享卡片的图，直接用 headless 浏览器渲染真实画面截的
- `apple-touch-icon.png`（180×180）给 iOS「添加到主屏幕」用

⚠️ **`og:image` 和 `og:url` 必须写绝对地址** —— 抓取的一方（微信、Twitter 的服务器）
不会解析相对路径。所以这两处写死了 `https://alexsheng26.github.io/3D-snake/`。
**换仓库名、换用户名或者换域名时，记得改这两行**，否则卡片会显示不出图。

## 音效

**没有任何音频文件**，所有声音都是用 Web Audio 现场合成的（振荡器 + 包络，
撞墙的闷响是一段白噪声过低通）。所以文件还是单个 HTML，照样能离线跑。

| 时机 | 声音 |
| --- | --- |
| 转向 | 极短的一声轻响 |
| 吃红果 | 两个音往上跳，音高随分数缓慢爬升，连吃有递进感 |
| 吃金果 | 四音上行琶音，明显比红果"值钱" |
| 金果出现 | 高处一点微光似的提示音，提醒你去追 |
| 金果超时 | 一声下滑，告诉你错过了 |
| 撞墙 | 下滑锯齿音 + 闷响 |
| 破纪录 | 死亡音之后接一小段上行 |

左下角按钮或 `M` 键开关，选择记在 localStorage 里。整体音量调 `SFX.vol`。

浏览器规定必须先有用户操作才能出声，所以 `AudioContext` 是在你第一次
按键 / 点击时才创建的 —— 打开页面本身不会突然响。老浏览器没有 Web Audio
的话会静默降级，游戏照常玩。

## 果实

| | 分数 | 说明 |
| --- | --- | --- |
| 红果 | 1 分 | 常驻，吃掉立刻在别处刷新 |
| 金果 | **2 分** | 有几率刷出来的限时果实 |

金果会转得更快、光晕更大更亮，旁边还有三块小方块绕着转，一眼能认出来。
**地上那圈光晕就是倒计时**，时间越少收得越紧，跳动也越急。7 秒内没吃到，
它会原地变回普通红果 —— 不会让你突然没东西可追。得分到 2 分以后才开始出金果。

这些都在 `CONFIG.gold` 里：`chance`（出现概率）、`points`（分数）、
`ttlMs`（限时）、`minScore`（多少分之后才出）。

## 名字和计分榜

开局卡片上可以填**本局用的名字**（最多 12 个字，留空就是「无名玩家」），
上次用的名字会记住并自动填上。死亡时这一局会记进计分榜，结算卡片上直接显示
排名，本局那一行高亮。0 分的局不记榜。

榜右上角有 **清空** 按钮。删记录是不可逆的，所以要**点两下**：第一下变成
「确定清空？」，第二下才真删；4 秒不点会自动取消（时长在 `CONFIG.clearConfirmMs`）。
没用 `confirm()` 弹窗 —— 它在 iframe 里可能被拦，样式也不受控。

计分榜存在浏览器的 localStorage 里（`snake3d.scores`），也就是说：
**只在这台设备的这个浏览器里有效**，换设备 / 换浏览器 / 无痕模式都看不到，
更不会跨玩家同步。想要真正的排行榜得配个后端，目前是纯本地的。

## 技术上是怎么做的

整个游戏就是根目录下的 `index.html`，**一个文件、零依赖**：没有 three.js，没有 CDN，
渲染是直接手写的 WebGL（约 200 行着色器 + 矩阵代码）。这样文件能离线跑、
能直接双击打开，后面想换成 three.js 也不会有历史包袱。

文件内部按注释分成几段：

| 段 | 内容 |
| --- | --- |
| `0. 可调参数` | `CONFIG`：棋盘大小、速度、配色、相机角度。**调手感基本只动这里** |
| `1. 迷你矩阵库` | `mat4` / 法线矩阵，够用就好 |
| `2. WebGL 底座` | 着色器、几何体（立方体 / 球 / 面片）、`solid()` `decal()` 两个画东西的入口 |
| `3. 游戏状态` | 蛇、果实、计分榜、`step()` 走一步的逻辑 |
| `4. 输入` | 键位 → 屏幕方向 → 网格方向的映射 |
| `5. 渲染` | 自动取景相机 + 每帧画场景 |

几个值得知道的实现细节：

- **逻辑按格子走，画面是插值的。** `step()` 一次挪一格，渲染时用
  `prev → 当前` 的插值，所以看着是平滑滑动而不是一格一格蹦。
- **相机自动取景。** `cameraFrame()` 会迭代算出刚好装下整块棋盘的距离，
  再用投影矩阵做「镜头平移」把棋盘摆正中间。窗口比例随便变、视角随便转，
  甚至手机竖屏都不会切边，所以不用手调 `dist`。
  **想让棋盘在屏幕上更大 / 更小，调 `CONFIG.cam.fill`**（棋盘占画面的比例，
  1.0 就是顶到画面边缘），不要去动 `dist`。
- **按键映射跟着视角转。** `screenDir()` 把「屏幕上的上下左右」投影到网格轴上，
  转了视角之后 `W` 还是画面里的「往上」。
- **蛇身的接缝是「接头」补的。** 每节仍然是独立的方块，但相邻两节之间会再画一根
  方柱，沿两节中心的连线摆（绕 Y 转 `atan2`），把拐弯处的断口填平。
  转弯插值到一半时两节最近会靠到 0.71 格，接头会跟着缩短、跟着转，
  所以直行和转弯都是连着的。比生成一整条管状网格便宜得多。
- **阴影是假的。** 每个物体在地面画一个按光照方向偏移的软圆片（`shadow()`），
  没有 shadow map。够用，而且便宜。接头不单独画影子——每节的影子够大，
  本来就连成一条了。
- **光照**：半球环境光 + 一道平行光 + 高光 + 边缘光，最后做一次色调压缩。
- **声音也是"手写"的。** 没有音频文件，`SFX` 里用振荡器 + 增益包络合成，
  跟渲染那边不用 three.js 是同一个思路：零依赖，离线可跑。

## 已知的偷懒之处 / 下一步可以做

- 蛇身还是一节节方块拼的（只是接缝补上了），侧面仍然是硬边。想要真正圆滑的
  身体，得沿路径生成一条带圆角的管状网格。
- 没有真阴影、没有抗锯齿以外的后处理（没有 bloom，果实的「发光」是假的）。
- 特殊果实目前只有金果一种。加速 / 减速 / 缩短身体之类的还没做。
- `CONFIG.wrap` 改成 `true` 就是撞墙穿到对面的模式，穿墙的插值已经处理过了，
  但没做穿墙的视觉提示。
- 没有背景音乐；音量只有开 / 关，没有滑杆（要调整体音量改 `SFX.vol`）。
- 没有 UI 设置面板（速度 / 棋盘大小现在只能改代码）。
- 计分榜只存本地，换台机器就没了。
- 相机是固定俯视整盘。棋盘调大之后可能需要改成跟着蛇头走。
