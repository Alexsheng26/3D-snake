# 3D 贪吃蛇（雏形）

45° 俯视视角的立体贪吃蛇。棋盘、蛇身、果实全部是真的 3D 几何体，
不是 2D 贴图伪装的立体感。

## 怎么跑

不需要装任何东西，也不联网：

```
直接双击 snake3d/index.html
```

或者起个本地服务（想用 localStorage 存最高分的话推荐这种）：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000/snake3d/
```

## 操作

| 键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 转向（按的是**屏幕方向**，转过视角也不会按反） |
| `Enter` | 在名字输入框里按，直接开局 |
| `Space` | 暂停 / 继续；死了之后是重开 |
| `R` | 重开 |
| `Q` `E` 或鼠标拖拽 | 左右转视角 |

手机 / 平板会自动显示右下角的方向键。

## 果实

| | 分数 | 说明 |
| --- | --- | --- |
| 红果 | 1 分 | 常驻，吃掉立刻在别处刷新 |
| 金果 | **2 分** | 有几率刷出来的限时果实 |

金果会转得更快、光晕更大更亮，旁边还有三块小方块绕着转，一眼能认出来。
**地上那圈光晕就是倒计时**，时间越少收得越紧，跳动也越急。7 秒内没吃到，
它会原地变回普通红果 —— 不会让你突然没东西可追。得分到 2 分以后才开始出金果。

这些都在 `CONFIG.gold` 里：`chance`（出现概率）、`points`（分数）、
`ttlMs`（限时）、`minScore`（多少分之后才出）。

## 名字和计分榜

开局卡片上可以填**本局用的名字**（最多 12 个字，留空就是「无名玩家」），
上次用的名字会记住并自动填上。死亡时这一局会记进计分榜，结算卡片上直接显示
排名，本局那一行高亮。0 分的局不记榜。

计分榜存在浏览器的 localStorage 里（`snake3d.scores`），也就是说：
**只在这台设备的这个浏览器里有效**，换设备 / 换浏览器 / 无痕模式都看不到，
更不会跨玩家同步。想要真正的排行榜得配个后端，目前是纯本地的。

## 技术上是怎么做的

整个游戏是**一个 HTML 文件、零依赖**：没有 three.js，没有 CDN，
渲染是直接手写的 WebGL（约 200 行着色器 + 矩阵代码）。这样文件能离线跑、
能直接双击打开，后面想换成 three.js 也不会有历史包袱。

文件内部按注释分成几段：

| 段 | 内容 |
| --- | --- |
| `0. 可调参数` | `CONFIG`：棋盘大小、速度、配色、相机角度。**调手感基本只动这里** |
| `1. 迷你矩阵库` | `mat4` / 法线矩阵，够用就好 |
| `2. WebGL 底座` | 着色器、几何体（立方体 / 球 / 面片）、`solid()` `decal()` 两个画东西的入口 |
| `3. 游戏状态` | 蛇、果实、计分榜、`step()` 走一步的逻辑 |
| `4. 输入` | 键位 → 屏幕方向 → 网格方向的映射 |
| `5. 渲染` | 自动取景相机 + 每帧画场景 |

几个值得知道的实现细节：

- **逻辑按格子走，画面是插值的。** `step()` 一次挪一格，渲染时用
  `prev → 当前` 的插值，所以看着是平滑滑动而不是一格一格蹦。
- **相机自动取景。** `cameraFrame()` 会迭代算出刚好装下整块棋盘的距离，
  再用投影矩阵做「镜头平移」把棋盘摆正中间。窗口比例随便变、视角随便转，
  甚至手机竖屏都不会切边，所以不用手调 `dist`。
  **想让棋盘在屏幕上更大 / 更小，调 `CONFIG.cam.fill`**（棋盘占画面的比例，
  1.0 就是顶到画面边缘），不要去动 `dist`。
- **按键映射跟着视角转。** `screenDir()` 把「屏幕上的上下左右」投影到网格轴上，
  转了视角之后 `W` 还是画面里的「往上」。
- **蛇身的接缝是「接头」补的。** 每节仍然是独立的方块，但相邻两节之间会再画一根
  方柱，沿两节中心的连线摆（绕 Y 转 `atan2`），把拐弯处的断口填平。
  转弯插值到一半时两节最近会靠到 0.71 格，接头会跟着缩短、跟着转，
  所以直行和转弯都是连着的。比生成一整条管状网格便宜得多。
- **阴影是假的。** 每个物体在地面画一个按光照方向偏移的软圆片（`shadow()`），
  没有 shadow map。够用，而且便宜。接头不单独画影子——每节的影子够大，
  本来就连成一条了。
- **光照**：半球环境光 + 一道平行光 + 高光 + 边缘光，最后做一次色调压缩。

## 已知的偷懒之处 / 下一步可以做

- 蛇身还是一节节方块拼的（只是接缝补上了），侧面仍然是硬边。想要真正圆滑的
  身体，得沿路径生成一条带圆角的管状网格。
- 没有真阴影、没有抗锯齿以外的后处理（没有 bloom，果实的「发光」是假的）。
- 特殊果实目前只有金果一种。加速 / 减速 / 缩短身体之类的还没做。
- `CONFIG.wrap` 改成 `true` 就是撞墙穿到对面的模式，穿墙的插值已经处理过了，
  但没做穿墙的视觉提示。
- 没有音效，没有 UI 设置面板（速度 / 棋盘大小现在只能改代码）。
- 计分榜只存本地，换台机器就没了；也没有「清空记录」的入口。
- 相机是固定俯视整盘。棋盘调大之后可能需要改成跟着蛇头走。
